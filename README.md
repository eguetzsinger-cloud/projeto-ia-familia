# Projeto de Fluxo de IA — Direito de Família

Projeto acadêmico desenvolvido para a disciplina de Inteligência Artificial Jurídica.

## Objetivo

Construir e documentar um fluxo de trabalho com Inteligência Artificial aplicado a um caso jurídico inteiramente fictício de Direito de Família.

O caso trata de uma divergência entre dois responsáveis sobre a organização da convivência familiar, férias escolares e responsabilidades relacionadas a uma criança.

## Público

O projeto é destinado à avaliação acadêmica e à demonstração de um fluxo verificável de uso de IA em uma tarefa jurídica.

## Limites

- Todos os nomes, fatos, datas e circunstâncias do caso são fictícios.
- Não foram utilizados processos, clientes ou documentos reais.
- A IA não substitui a análise jurídica ou a decisão humana.
- As respostas devem ser verificadas nas fontes indicadas.
- O projeto não tem finalidade de prestar aconselhamento jurídico real.

## Estrutura

- `entrada/` — relato inicial do caso.
- `apoio/` — versão sanitizada e fontes jurídicas selecionadas.
- `docs/` — limites, sigilo e especificação do fluxo.
- `prompts/` — instruções utilizadas na consulta com RAG manual e na auditoria.
- `evidencias/` — registros das respostas, verificações, auditoria e revisão humana.
- `entrega/` — orientação inicial revisada após as etapas de conferência.

## Critérios de aceitação

O fluxo deve:
1. utilizar somente o caso fictício;
2. separar relato bruto de versão sanitizada;
3. indicar as fontes utilizadas;
4. limitar a consulta de RAG às fontes selecionadas;
5. registrar a verificação das afirmações;
6. registrar a auditoria;
7. apresentar uma revisão humana;
8. produzir uma orientação final com limites claros.
