# Prompt — RAG manual

## Instrução utilizada

Analise o caso fictício descrito em `apoio/caso_sanitizado.md`.

Use exclusivamente os conteúdos disponíveis em:
- `apoio/fonte_1.md`;
- `apoio/fonte_2.md`.

Não use outras fontes, decisões judiciais, notícias ou conhecimento externo.

Para cada afirmação jurídica relevante:
1. indique se ela está apoiada em uma das fontes;
2. informe o nome do arquivo;
3. indique o artigo, tópico ou trecho utilizado;
4. diferencie o que está expressamente previsto daquilo que é apenas inferência;
5. quando não houver suporte suficiente, escreva "não confirmado pelas fontes selecionadas".

Não invente artigos, fatos ou decisões.

Ao final, produza uma orientação inicial curta sobre quais pontos da convivência familiar devem ser organizados e quais aspectos precisam de revisão humana.

A resposta não deve ser apresentada como parecer jurídico definitivo.
